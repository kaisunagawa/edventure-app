# JIROKU（自録）── プロダクト全体像

> **この文書の目的**
> JIROKUというプロダクトが「何であり、誰のためで、何ができて、どんな事業になっているか」を
> 一つにまとめたものです。LP制作・営業資料・提案書などの元資料として使うことを想定しています。
>
> 記載内容は 2026年8月10日 時点の**実装済みの機能**が基準です。
> 構想段階のものは「未実装」と明記しています。数字はすべて実データです。

---

## 1. 一言でいうと

**時間の使い方を1時間ごとに記録して、AIコーチと一緒に振り返る「自己経営」アプリ。**

3か月の目標から今日やることまでを一本の線でつなぎ、毎日の記録でその進み具合を確かめます。
記録するとAIが毎晩レポートを返し、続けるほど言葉が本人に近づいていきます。

**「1時間ごとに、何をしたかを選んで記録する」だけ。** あとはAIが分析します。

### 従来の習慣化アプリとの違い

| | 一般的な習慣アプリ | JIROKU |
|---|---|---|
| 記録するもの | 「やったか／やらなかったか」のチェック | **何をしたか・どう感じたか（言葉）** |
| フィードバック | 連続日数・達成率 | **AIが文章で毎晩返す** |
| 時間の扱い | 記録しない | **1日を時間帯で埋めて可視化する** |
| 目標との接続 | 個別のタスク単位 | **3か月目標まで一本でつながる** |
| 続ける仕組み | 通知のみ | 通知＋AI＋ゲーム要素＋仲間＋人のコーチ |

**核心：チェックを付けて終わりではなく、行動そのものを読み取って言葉で伴走する。**

---

## 2. 解決したい課題

- 続けたいことがあるのに、気づけば1日が終わっている
- 何にどれだけ時間を使ったか、思い出せない
- 手帳もアプリも、いつのまにか開かなくなった
- 一人だと、つい後回しにしてしまう

**足りないのは根性ではなく「続く仕組み」** ── これがプロダクトの前提です。

## 4. 中核となる4つの体験

### ① 記録する（1件30秒）

1日を1時間ごとの時間帯に区切り、そこで何をしたかを残します。

- 時間帯を選ぶ（00:00〜24:00、全24枠）
- 何をしたかを入力
- 自己評価を5段階で選ぶ
- **時間の種類を6分類から選ぶ**
- メモを書く（ここが最も重要）

**時間の6分類**（上ほど望ましい使い方、下ほど減らしたい）

| 分類 | 選ぶ目安 |
|---|---|
| 目標に直結 | 3か月目標に直接効いた時間 |
| 将来への投資 | すぐ効かないが将来のためになる学習・仕込み |
| 回復 | 休息・睡眠・運動など、充電になった時間 |
| 人間関係 | 人と会う・話す・つながりを保つ時間 |
| 日常業務 | やらないと回らない日常の作業 |
| 計画外の時間 | 予定になかった割り込み・流されて使った時間 |

分類は任意で、あとから変更できます。前回選んだ分類が次の初期値になります。

**入力を軽くする4つの手段**

| 手段 | 内容 |
|---|---|
| まとめて記録 | 同じ内容が続いた複数の時間帯を一括保存 |
| 独り言 | 画面右下のボタンから、話すだけ・書くだけで記録 |
| 集中タイマー | ポモドーロ。終了するとそのまま記録になる |
| Googleカレンダー連携 | 予定が記録の候補として自動で入る |

### ② 目標とつなげる（目標ロードマップ）

**3か月目標 → 2週間目標 → 今週の目標 → 今日のタスク** を一本の線でつなぎます。

- 各段階に進捗バーがあり、「＋追加する」で実績を積み上げる
- 3か月目標は複数持てる
- 日々の記録がどの目標に効いたかが見える
- AIもこの構造を踏まえて声をかける

### ③ 振り返る（AIレポート）

**毎晩22時**、その日の記録をもとにAIが点数と文章を返します。

**採点の5項目（各20点・計100点）**

| 項目 | 見ているもの |
|---|---|
| 記録数 | 記録した時間帯の多さ |
| メモ | 振り返りの深さと量 |
| 集中度 | 自己評価の平均 |
| 目標との関係 | 目標に関連した記録の割合 |
| 継続 | 連続記録日数 |

点数はアプリが記録から計算し、AIには決めさせません（画面とLINEで食い違わないため）。
レポートには、良かった点・改善点・明日のアクション1つ・成長のトレンドが含まれます。

### ④ 続ける（ゲーム要素と仲間）

- **XP・レベル**（1〜100）と**階級**：記録するほど上がる
- **隠しジロー**：特定の条件を満たすと出会えるキャラクター。図鑑・攻略本つき
- **みんなの頑張り**：他の利用者の記録状況とランキングが見える
- **連続記録日数**（ストリーク）

## 5. AIが担っている11の役割

JIROKUは単発のAI機能ではなく、**1日の流れ全体にAIが配置されています。**

| タイミング | 機能 | 内容 |
|---|---|---|
| 朝7時 | 朝の予定通知 | 今日の予定と目標を踏まえた個別メッセージ |
| 毎時 | 記録リマインダー | 記録状況に応じて声かけを変える |
| 夜22時 | 夜のレポート | その日の点数とフィードバック |
| 夜22時30分 | コーチからの一言 | もう一段踏み込んだ声かけ |
| 随時 | 独り言の要約 | 話した内容から記録を組み立てる |
| 随時 | 1日のまとめ | 記録から日記を生成 |
| 月次 | 気づき | 蓄積された記録から本人の傾向を抽出 |
| 月次 | 時間テーマ | 時間の使い方の傾向を言語化 |
| 月次 | 月次サマリー・月次レビュー | 長期の変化を振り返る |
| 随時 | 過去に聞く | 自分の全記録に質問できる |
| 随時 | 業務報告書 | 仕事の記録だけを抽出して上司向けの報告文を生成 |

**利用者ごとに文脈が違います。** 直近14日の全記録、月次サマリー、レポート履歴、目標、
カレンダー予定、コーチとの面談記録、そして**初回アンケートの回答**が毎回AIに渡ります。

**声かけのトーンは本人が選べます**（優しく応援／厳しめに喝／データで淡々と／一緒に伴走）。
選んだトーンはAIへの指示として明示的に渡され、レポートや通知の言い回しに反映されます。

**使用モデル**：品質が直接見える機能はClaude Opus 5、日常的に高頻度で動く機能はClaude Haiku 4.5。
学生向けは中間のSonnet 5でコストを抑えています。

## 11. JIROKU Studio（開発中・未公開）

**記録を発信に変えるモジュール**です。実装は完了していますが、まだ公開していません。

- JIROKUの記録と日記から、AIがSNSの発信ネタと台本を生成
- **どの記録から生まれた台本かを記録単位で保持**（ここが他ツールにない部分）
- 機密リスク・共感スコア・具体性を自動判定し、公開前チェックを出す
- 気づいたことをJIROKU本体のタスクに書き戻す（記録 → 発信 → 成果 → 次の行動の循環）
- Instagram連携は実装済み。Meta側のアプリ登録待ち

**位置づけ**：SNS運用ツールではなく、自己経営OSに「発信・市場検証・信用形成」を足す拡張。

## 12. 技術構成

| 層 | 実装 |
|---|---|
| フロントエンド | 単一HTMLのPWA（React + htm）。GitHub Pagesで配信 |
| バックエンド | Google Apps Script（Webアプリ） |
| データベース | Googleスプレッドシート（28シート） |
| AI | Claude API（Opus 5 / Sonnet 5 / Haiku 4.5 を用途で使い分け） |
| 認証 | Googleログイン＋セッショントークン（署名検証・失効管理あり） |
| 定期処理 | Apps Scriptのトリガー17本（毎分・毎時・毎日・毎週・毎月） |

- API : 237アクション
- 画面 : 利用者用6タブ（ホーム／タイマー／記録／レポート／気づき／設定）＋コーチ用アプリ＋Studio
- サーバー費用 : **0円**（GitHub Pages・Apps Script・スプレッドシートの無料枠）
- AI費用 : **月およそ1,800円**（実測）

**特徴：インフラを持たずに運用している。** スケール時はSupabase等への移行を想定。

## 13. 実績（2026年8月10日時点・実データ）

| 指標 | 数値 |
|---|---|
| 登録者 | 38人 |
| 一度でも記録した人 | 26人 |
| 直近14日に記録した人 | 16人 |
| **1週間以上、記録が続いた人** | **15人**（記録した26人のうち） |
| 記録の総数 | **1,850件** |
| AIレポート生成数 | 289件 |
| 初回アンケート回答者 | 20人（平均12問／13問中） |

**声かけの好みの内訳**：一緒に伴走 9人／厳しめに喝 8人／優しく応援 3人

> **数字の扱いについて**
> 母数が小さいため、率（％）ではなく実数で示すことを推奨します。
> 「継続率58%」より「記録した26人のうち15人が1週間以上続けています」のほうが誠実で、説得力もあります。
> レポートの平均点（46.2点）は、満点が全時間帯を埋めた場合の設計のため低く出ます。**対外的な使用は非推奨。**

## 14. プロダクトの思想（LP制作時に外してほしくない点）

1. **「やる気が足りない」のではない。** 足りないのは続く仕組み。責める設計にしない
2. **チェックではなく言葉。** 行動そのものを読み取って伴走する
3. **点数は本人を測る道具であって、順位づけの道具ではない。** 記録が薄い日も責めない
4. **一人でやらせない。** AI・仲間・人のコーチの3層で支える
5. **アプリを渡して終わりにしない。** 必ず人が最初に伴走する
6. **続けるほど自分に近づく。** 記録が増えるほど、返ってくる言葉が自分専用になる
