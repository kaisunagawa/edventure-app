## B案：アプリ内・詳しく読みたい人向け

```
### この数日のアップデート（2026年8月1日〜5日）

**目標ロードマップ（全員に公開）**
3か月目標 → 2週間スプリント → 今週の目標 → 今日のフォーカス を1枚でつなぎました。
進捗バー・達成率・「残り◯◯・あと◯日・必要なペース」が出ます。
「＋ 追加する」で進んだぶんを足せて、長押しで履歴を開いて直せます。
3か月目標が複数ある人は、丸いボタンで切り替えられます。

**自己経営の状態**
5つの力（成果力・時間配分力・実行力・継続力・立て直し力）と総合スコア。
前週比と「上位◯%」も出ます。
状態の札は、青=強み／緑=安定／黄=要確認／赤=改善優先／灰=暫定（まだ測れていない）。
「詳細を見る」で、点数の理由と改善策が読めます。

**ジローくんと階級システム**
キャラクターに名前がつきました。名前は JIROKU（時録）から。
階級が上がると姿が変わります。まだ到達していない階級の姿は見えません。

| 階級 | レベル |
|---|---|
| ルーキー | 1–5 |
| チャレンジャー | 6–15 |
| コンシステント | 16–30 |
| 習慣マスター | 31–50 |
| エキスパート | 51–75 |
| レジェンド | 76–100 |

Lv.100 が頂点です。XPの稼ぎ方は変えていません。刻み方だけを100段階にしました。
これまでの到達点をそのまま引き継ぐよう設計したので、階級が下がる人はいません。

**記録**
- 時間の分類を6つに（目標に直結／将来への投資／回復／人間関係／日常業務／計画外の時間）
- 「まとめて分類する」で、たまった記録をまとめて片づけられます
- 記録の時刻を押すと「記録の時間を直す」が開きます。長さを変える／前後にずらす
- 「＋ 記録を追加する」で、まだ記録していない時間帯がすぐ開きます
- 13:00〜15:40のような記録が、1時間ごとに分かれず1件で残ります
- 削除ボタンを、全部消さなくても押せるようにしました

**Googleカレンダー**
記録が分類ごとの色で入ります（目標に直結＝青、将来への投資＝紫、回復＝緑、
人間関係＝黄、日常業務＝水色、計画外の時間＝灰）。

**速くなりました**
- 起動時の通信を4回から1回にまとめました
- レポートを開くときの待ち時間をなくしました
- 「1日に使える時間」の設定を、1タップごとではなく最後にまとめて保存するようにしました

**直したところ**
- パソコンと携帯で、タスクの時間や表示が食い違う
- 記録したのに「まだ今週の記録がありません」と出る
- 記録や分類を変えても、自己経営の状態が最大6時間そのまま
- 夜の記録が翌日の日付になる
- 今の分類に無い古い記録が「分類済み」として数えられていた
- 押しても何も起きないボタンがいくつかあった

使い方ガイドも全面的に更新しています。
```
